# Laboratory 05: Cloud Data Engineer

**Name:** CCM Jaymark Alqueza

## Mission Overview

This laboratory explores cloud storage and deploys MinIO, an S3-compatible object storage server, using Docker. The proof of concept is designed for a photo-sharing client that needs storage independent of its application containers.

## Objectives

- Compare block, file, and object storage.
- Deploy MinIO in a Docker container and access its web console.
- Create the `client-photos` bucket and upload a test object.
- Document the deployment and reflect on cloud storage concepts.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO
- Web browser
- GitHub and Markdown

## Skills Learned

- Distinguishing cloud storage models and their use cases.
- Running a containerized storage service with environment variables and port mappings.
- Managing buckets and objects through a web console.
- Recording technical procedures and evidence in a portfolio.
